4. MILESTONE 7 OBJECTIVE
============================================================

The objective of Milestone 7 is:

Convert every valid document chunk into a numerical vector that
represents the semantic meaning of the chunk.

For example:

Input chunk:

"The Transformer architecture uses self-attention mechanisms."

Embedding model:

Sentence Transformer

Output:

[0.123, -0.431, 0.892, ...]

The vector is later used for semantic similarity search.

This milestone is the bridge between:

TEXT PROCESSING

and

VECTOR SEARCH / RAG.

============================================================
5. WHY EMBEDDINGS ARE REQUIRED
============================================================

Traditional keyword search depends heavily on matching exact words.

Example paper text:

"The Transformer architecture uses self-attention."

User question:

"How does the Transformer understand relationships between words?"

The exact words may be different.

Embeddings allow the system to represent both texts in a semantic
vector space.

Conceptually:

Paper chunk
    ↓
Embedding
    ↓
Vector

User query
    ↓
Embedding
    ↓
Query vector

Later:

Query vector
    ↓
Vector similarity search
    ↓
Relevant chunks

This is the foundation of semantic retrieval.
