# MILESTONE 20 — PRODUCTIONIZATION, OBSERVABILITY, EVALUATION & DEPLOYMENT

## PROJECT CONTEXT

I am building an AI Research Assistant.

Milestones 1–19 have already been completed.

The application currently supports the complete research lifecycle:

1. Authentication and Authorization
2. Research Workspaces
3. PDF Upload
4. PDF Text Extraction
5. Document Chunking
6. Embedding Generation
7. Vector Database
8. RAG Question Answering
9. LangGraph Autonomous Research Agent
10. Citation and Source Grounding
11. Advanced Paper Summarization
12. Multi-Paper Comparison
13. Literature Review
14. Research Gap Detection
15. Research Question and Hypothesis Generation
16. Research Proposal and Methodology Planning
17. Experiment Planning and Statistical Planning
18. Experiment Execution, Tracking and Results Analysis
19. Automated Research Paper and Final Report Generation

The system is now functionally complete.

Milestone 20 must transform the application into a reliable, observable, secure, testable, scalable and deployable production system.

- failure handling

# 11. PROMPT INJECTION DEFENSE

Research papers and retrieved documents are untrusted input.

Treat document text as DATA, not instructions.

The system must distinguish:

SYSTEM INSTRUCTIONS

from

USER INSTRUCTIONS

from

DOCUMENT CONTENT

from

RETRIEVED CONTEXT

A paper containing:

"Ignore previous instructions..."

must not override the system's instructions.


# 12. CITATION SAFETY

- system instructions
- tool execution
- authorization
- database queries
- application configuration

Retrieved text must remain untrusted content.
