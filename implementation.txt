============================================================
1. MAIN OBJECTIVE
============================================================

Build an AUTONOMOUS AI RESEARCH AGENT using LangGraph.

The agent must NOT simply follow a fixed sequence of rules.

The agent must be able to:

1. Understand the user's request.
2. Determine whether it needs any tools.
3. Decide whether it can answer directly.
4. Decide which tool is appropriate.
5. Call the selected tool.
6. Observe the tool result.
7. Evaluate whether the result is sufficient.
8. Decide whether another tool call is required.
9. Continue reasoning/action when necessary.
10. Stop when enough information has been collected.
11. Generate a grounded final answer.

The agent should dynamically decide what to do.

============================================================

============================================================

    call_summary_tool()

if "author" in question:

Do NOT implement this architecture.

3. WHAT MAKES THIS AN AUTONOMOUS AGENT?
============================================================

The agent should have a decision loop.

Conceptually:

START
 ↓
Understand user request
 ↓
Assess available information
 ↓
Decide whether action is required
 ↓
If action required:
      choose tool
      ↓
      execute tool
      ↓
      inspect result
      ↓
      determine whether more information is required
      ↓
      repeat if necessary
 ↓
Generate final answer
 ↓
END

The number and order of tool calls should NOT be hard-coded.

The LLM should determine the path dynamically.

The agent must know when to stop.

Potential stopping conditions:

User question has been answered.
Sufficient evidence has been retrieved.
No additional tool is necessary.
Tool results are sufficient to generate a grounded answer.

evidence.
