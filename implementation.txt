MILESTONE 11 — CITATION & SOURCE GROUNDING SYSTEM
============================================================

The purpose of this milestone is to make every research-paper-based
answer traceable to the original source material.

The system should not simply generate:

"The paper uses a Transformer architecture."

It should generate something like:

"The paper uses a Transformer architecture [1]."

And provide:

[1] Research Paper Name
    Page 3
    Chunk 17

The user must be able to understand where the information came from.
