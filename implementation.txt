# MILESTONE 18 — EXPERIMENT EXECUTION, TRACKING & RESULTS ANALYSIS

## 1. PROJECT CONTEXT

I am building an AI Research Assistant.

Milestones 1–17 have already been completed.

The system currently supports:

- Authentication and authorization
- Research workspaces
- PDF upload

- Methodology planning

    ↓

    ↓
Research Conclusion

The objective of Milestone 18 is to allow the researcher to execute experiments defined in Milestone 17, capture REAL experiment results, compare experiments, perform statistical analysis, visualize results, test hypotheses, and generate an evidence-based research conclusion.

IMPORTANT:

The LLM must NEVER invent experiment results.

Actual numerical results must come from executable experiment code, uploaded result files, or explicitly supplied researcher data.

The LLM may ONLY interpret actual results.


# 2. CORE OBJECTIVE

Implement a complete experiment execution and analysis subsystem.

The researcher should be able to:

1. Select a research proposal.
2. Select an experiment from the experiment plan.
3. Configure the experiment.
4. Run the experiment.
5. Track execution status.
6. Capture logs.
7. Store experiment artifacts.
8. Store actual metrics.
9. Compare experiments.
10. Run statistical analysis.
11. Perform hypothesis testing.
12. Analyze ablation studies.
13. Visualize results.
14. Ask the AI to interpret the results.
15. Generate research findings.
16. Generate a research conclusion.
17. Save the results.
18. Reproduce the experiment.
19. Export the experiment report.

# 27. BASELINE VS PROPOSED COMPARISON

Compare experiments according to the actual metrics.

Example:

Dense:
Recall@10 = 0.86

Hybrid:
Recall@10 = 0.91

Absolute improvement:

0.05

Relative improvement:

(0.91 - 0.86) / 0.86 × 100

Do this calculation deterministically.

Do not ask the LLM to calculate basic numerical differences.

# 34. HYPOTHESIS TESTING

Connect actual results to Milestone 16 hypotheses.

Example:

Research Question:

Does hybrid retrieval improve retrieval performance?

H0:
Hybrid retrieval does not improve performance.

H1:
Hybrid retrieval improves performance.

Actual results:
Hybrid = 0.91
Dense = 0.86

Statistical analysis:
p < selected significance threshold

Conclusion:

Reject H0 under the selected statistical procedure.

IMPORTANT:

The system must not conclude that H1 is true merely because one value is larger.

Statistical evidence and experimental design must support the conclusion.

# 46. CAUSALITY SAFETY

The system must distinguish:

Correlation:

"X was associated with Y."

Causal evidence:

"X caused Y."

Only use causal language when the experiment design justifies causal inference.

Otherwise use:

- associated with
- correlated with
- observed alongside
- resulted in under the experimental setup

Do not overstate conclusions.
